# Demo 8 — MCP (GitHub o filesystem)

**Cuándo:** Fuera de las 2 h o si MCP ya está configurado. **No improvisar setup en clase.**

---

## Opción A — MCP GitHub (recomendado si está listo)

**Repo:** el del workshop o `clinica-turnos` publicado en GitHub.

### Prompt

```
Usá la herramienta de GitHub (MCP) para:

1. Listar issues abiertos de este repositorio
2. Elegir el más relacionado con reservas/appointments (o crear un resumen si no hay)
3. NO implementar código

Entregable:
- Título y número del issue
- Resumen en 3 bullets
- Propuesta de primer commit: qué archivo SPEC o doc agregarías

Si la herramienta falla, decilo explícitamente. No inventes issues.
```

---

## Opción B — MCP filesystem (sin GitHub)

**Proyecto:** `demos/clinica-turnos`

### Prompt

```
Usá MCP filesystem (o leé archivos con tus tools):

1. Listá archivos en docs/ y la raíz del proyecto
2. Leé SPEC.md y AGENTS.md
3. Identificá qué regla de SPEC.md todavía no tiene test en tests/

No escribas código. Entregá una tabla: Regla | ¿Test? | Nombre sugerido del test
```

- ¿Admite error de conexión?
